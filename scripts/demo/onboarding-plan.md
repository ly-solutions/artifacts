# Onboarding plan for new engineers

The first two weeks, day by day. Each step names who helps and what "done" looks like.

## Week one

- **Day 1.** Laptop, accounts, and a first commit to the handbook.
- **Day 2.** Run the stack locally; ship a typo fix through CI to production.
- **Days 3–5.** Pair with a buddy on a real ticket from the current sprint.

## Week two

- Own a small ticket end to end, including the rollout.
- Join one incident review as an observer.
- Write down three things that confused you; we fix the docs together.
